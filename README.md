# CRUD API - Gestão de Pessoas (CI/CD Pipeline)

Projeto prático desenvolvido para a disciplina de **Integração e Entrega Contínua (CI/CD)**.
Consiste em uma API RESTful para gerenciamento de pessoas com cálculo dinâmico de idade, desenvolvida seguindo práticas de TDD, análise estática, testes automatizados e containerização.

---

## 📋 Requisitos e Regras de Negócio

- **Dados da Entidade:** CPF, Nome, Data de Nascimento e Idade (calculada dinamicamente).
- **Armazenamento:** Repositório em memória para agilidade na execução dos testes e validação.

---

## 🌿 Estrutura de Branches (GitFlow)

- `main`: Branch de produção / versão estável final.
- `develop`: Branch de integração contínua.
- `feature/*`: Branches específicas para desenvolvimento de cada etapa (TDD, CRUD, lint/formatação, Docker).
